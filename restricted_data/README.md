# Qatar matched-control evidence boundary

The Qatar field/laboratory source workbook, commercial identities, BOM comparison evidence, and owner-held metrology records are confidential / owner-controlled and are not redistributed here.

Disclosure-safe publication may include coded configuration/specimen identifiers, derived diagnostics approved for release, evidence-state tables, exact-resampling outputs, scripts, tests, and provenance hashes.

If owner-held evidence changes BOM equivalence, the 2022 control baseline, procedure comparability, or uncertainty state, the manuscript calculation/interpretation gate must be reassessed rather than updated by wording alone.
